# Asset & Content Checklist

## Personal content
- [ ] Birthday date (optional)
- [ ] 3–8 selected memory photos
- [ ] Short caption for each photo
- [ ] Birthday letter (real words from the sender)
- [ ] Secret message
- [ ] Final closing message

## Visual assets
- [ ] Main pixel-art illustration
- [ ] Gift box illustration/sprite
- [ ] Pixel cake and candle illustration
- [ ] Small decorative stars/hearts
- [ ] Optional favicon

## Audio
- [ ] Music file that you own or have permission to use
- [ ] Confirmed file format and file path
- [ ] Play/pause behavior tested on mobile

## Suggested locations
- `public/images/memories/`
- `public/illustrations/`
- `public/music/`
- `public/fonts/`

## Asset safety
- [ ] Confirm consent/approval for photos
- [ ] Remove sensitive details from captions
- [ ] Do not upload private documents or credentials
- [ ] Remember: a public Vercel deployment is shareable by anyone with the URL
